# AI Animation Production Machine — Project Brief

الحالة: مرحلة التحليل — لا تنفيذ بعد
المستودع: eg250k-del/openclude

## الهدف النهائي
ماكينة AI Animation بأقل تدخل:

Film Idea / Long Text
  → Script → Characters → Character References
  → Scenes → Voice/Audio
  → Full Motion Animation
  → Scene Continuity
  → Automatic Assembly
  → Long Film (20min → 2h+)

مهم: full motion video — مش صور ولا slideshow
المرحلة التالية: multiple GPUs (بعد النسخة المستقرة فقط)

## خبرة المستخدم
- مبتدئ تمامًا في البرمجة
- خطوة واحدة في كل مرة + كود جاهز للنسخ
- الهدف = النتيجة مش تعلم البرمجة

## ما حدث سابقًا
- SaladCloud + RTX 4090 24GB + ComfyUI + Wan 2.2
- مشاكل في الـ Container
- فقدان موديلات Wan بعد إعادة التخصيص
- يوجد Container قديم — لا تحذفه

## Pipeline المطلوب
1. Input      — فكرة/قصة/script
2. Script     — AI يحوّلها script منظم
3. Characters — استخراج + character sheets
   (front/side/back/expressions/clothing)
4. Scenes     — تقسيم scenes ثم shots
   (مكان/شخصيات/حركة/كاميرا/حوار/مدة/صوت)
5. Voice      — narration + dialogue + character voices
   مدة الصوت تحدد مدة اللقطة
6. Video Gen  — Wan 2.2 full motion
7. Continuity — identity + environment + clothing
   + style + last-frame carry
8. Automation — queue, batch, retry, logging, resume
9. Assembly   — ترتيب + sync + merge + ffmpeg

## متطلبات قاسية
- فشل مشهد واحد = يُعاد هو فقط، لا الفيلم كله
- لا توليد ساعات دفعة واحدة — shots صغيرة ثم تجميع
- افحص متطلبات VRAM لكل workflow (24GB)
- فصل دائم: Repository | Checkpoints | Outputs | Cache
